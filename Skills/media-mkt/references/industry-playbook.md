## 1. 五平台一句话定位与推流逻辑

| 平台 | 一句话定位 | 推流看重什么 | 营销含义 |
|------|-----------|-------------|---------|
| **抖音** | 情绪击穿 + 算法爆发 + 即时转化 | 行为概率×价值加权（完播/评/藏/转/停留）；早期重完播 | 前几秒留存+有效互动比堆粉丝重要；适合情绪种草与即时收割 |
| **小红书** | 决策验证 + 搜索种草 + KOC口碑 | 搜推强联动、**收藏**权重高、可被搜到 | 标题/封面/关键词布局；测评对比避坑承接决策验证；KOC易冷启动 |
| **B站** | 圈层认同 + 深度定调 | 三连率、弹幕密度、完播、UP长期关系 | 长内容、系列化、社区认同；转化周期长 |
| **知乎** | 专业氛围 + 决策加码 | 赞同质量、权威度（威尔逊类+专业权重） | 全网种草后用深度回答补专业信任；适合需被说服的品类 |
| **快手** | 信任关系 + 普惠分发 | 去中心化、老铁信任、双列主动选择 | 人设信任、性价比、下沉与成熟用户；直播信任电商强 |

**核心原则**：同一产品，不同平台不同人格。不要一稿多投——抖音短钩子、小红书信息密度、B站章节论证、知乎问答结构、快手口语信任。

## 2. 跨平台种草时序（常见打法）

一场战役内容通常分阶段在不同平台推进：
1. **D0–D2 引爆**：B站深度 / 微博话题定调
2. **D3–D7 信任**：小红书测评矩阵承接搜索外溢
3. **D5–D14 收割**：抖音场景短视频 + 小黄车即时转化

> 用于解读"为什么某主题集中在某平台"，不是因果断言。看数据时可对照：某平台声量突出，可能正处在它擅长的战役阶段。

## 3. 各行业营销钩子（快消/医疗）

用户行业：快消/饮料、快消/奶粉、制药、医疗、医疗器材。同样的数据在不同行业指向不同动作：

| 行业 | 核心焦虑/钩子 | 内容主题重点 |
|------|--------------|-------------|
| **快消/饮料** | 场景（什么时候喝）、促销、口味 | 场景短视频、促销信息、新品测评 |
| **快消/奶粉** | 转奶焦虑、正品/版本（国行vs德爱、ab版）、安全 | 对比测评、避坑清单、正品鉴别 FAQ |
| **制药** | 科普需求、疗效顾虑、用药安全 | 科普向内容、专业背书；**严守合规** |
| **医疗** | 决策信任、专业权威、隐私顾虑 | 知乎/B站深度科普、专家背书 |
| **医疗器材** | 使用方法、价格、真伪辨别 | 使用教程、价格渠道、正品辨别 |

分析时主动往这些钩子上靠：看到奶粉内容就想"是不是在聊转奶/正品"，看到饮料就想"是不是场景/促销"。

## 4. KOL vs KOC 分层

| | KOL（关键意见领袖） | KOC（关键意见消费者） |
|--|--------------------|----------------------|
| 定位 | 粉丝大、影响力强 | 粉丝中低、真实感强 |
| 优势 | 声量、权威、破圈 | 真实、转化、铺量便宜 |
| 风险 | 贵、广告感、翻车影响大 | 单点声量小、质量不齐 |
| 算法友好 | 抖音更偏KOL爆发 | 小红书更利KOC冷启动 |
| 合作策略 | 少而精，战役头部引爆 | 多而散，形成"很多人都在用"的共识 |

金字塔投放：塔尖头部KOL（声量背书）+ 腰部垂类（专业信任）+ 塔基大量KOC/素人（铺量口碑）。母婴等信任优先品类常偏 KOC 重。

**分析创作者时看什么**：不只看粉丝数，看垂类匹配度、互动率（真实度）、内容主题、舆情风险（翻车/水军）、平台主阵地。

## 5. 合规红线（必须遵守）

制药/医疗/医疗器材是强监管行业。分析和建议时：
- **不得**建议夸大疗效、暗示确定治愈、编造成功率/有效率数字。
- 发现内容有夸大/违规表述时，**标注为风险**，不要当作可复用的优秀种草素材推荐。
- 涉及个人信息（评论线索）时，遵循最小化与合规留存。
- 平台对虚假种草、诱导互动有治理护栏；不建议诱导性打法。

## 6. 公域到私域的闭环

自媒体营销不是"发帖获客"，而是闭环：
```
听懂人（洞察） → 用内容触达互动（种草） → 用数据再研究人（研究/线索） → 迭代
```
- 公域（抖音/小红书/B站/知乎/快手）负责发现、种草、验证、转化。
- 私域（企微/社群/小程序）负责沉淀、复购、资产化。
- **公域流量可租，私域关系才是资产**。种草爆发后若不沉淀私域，等于每次重新付费触达同一批人。

建议动作里如果涉及"怎么留住这波流量"，往私域沉淀方向想（引流钩子、企微、分层运营）。
