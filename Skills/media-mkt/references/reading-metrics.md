## 1. 四个指标各自代表什么心理动作

数字背后是人的动作，每个动作暴露不同的心理深度：

| 指标 | 用户做了什么 | 暴露的心理 | 营销价值 |
|------|-------------|-----------|---------|
| **播放/曝光** | 划到了、看了 | 最浅，只代表被触达 | 判断触达规模，不代表认可 |
| **点赞** | 顺手认可 | 轻度共鸣「说得对」 | 内容对不对味的快信号 |
| **收藏** | 想留着以后用 | **决策意图**「我可能要买/参考」 | 极强的购买链路信号，尤其小红书 |
| **评论** | 愿意花时间打字 | 卷入最深：认同、提问、质疑、争论 | 讨论热度 + 舆情 + 线索金矿 |
| **分享** | 愿意用社交信誉背书 | 强认同或强实用 | 传播破圈潜力 |

**关键认知**：收藏和评论是"重动作"，比点赞更值钱。一条**收藏率**高的内容说明它戳中了真实需求（用户想留着照做/照买）；一条**评论率**高的内容说明它引发了讨论（可能是爆点，也可能是争议）。

## 2. 互动结构：比例比总量更会说话

同样的总互动量，不同的**内部比例**是完全不同的市场信号。学会读结构：

### 赞 vs 评的关系
- **赞 >> 评**（赞高评论少）：**安静的认可**。内容说到了大家心坎里，没什么可争的 → 观点已是共识，适合直接复用其结构做种草。
- **评 ≥ 赞 或 评/赞比异常高**：**热烈的讨论或纠结**。要么是爆点话题，要么是有争议/有疑问 → 一定要去读评论，判断是正向讨论还是购买犹豫/负面。

### 藏 vs 赞的关系（尤其小红书）
- **藏 > 赞**：用户"懒得点赞但要收藏照做"——**极强的决策信号**，说明内容有实用价值、用户真的想按它行动（买/试/参考）。这类内容是种草金矿。
- **赞 > 藏很多**：叫好不叫座，看着爽但没转化意图。

### 藏 + 评 同高
说明既有决策意图又有讨论热度 → 通常是品类里的**关键决策内容**，值得重点研究它在说什么。

### 一个判读模板
拿到一条内容，先问三句：
1. 它的**重动作**（藏/评）是不是明显高于轻动作（赞）？→ 决定它有没有决策价值。
2. 评论是不是**盖过**点赞？→ 决定要不要深挖评论找争议/线索。
3. 放到**同平台同批次**里，它是不是相对突出？→ 决定它是不是真的"重点"（绝对数没意义）。

## 3. 各平台字段口径（别用错分母）

跨平台算互动率时，分母和权重都不一样，用错就是外行：

| 平台 | 常缺字段 | 权重侧重 | 算互动率的注意点 |
|------|---------|---------|-----------------|
| 抖音 | 公开接口**常无播放量** | 播放+完播+多目标行为 | 无播放时别硬算完播率；用互动总量或同平台相对位次 |
| 小红书 | 常无播放量 | **收藏权重极高**、搜索可见性 | 分母用互动总量；收藏要单独重点看 |
| B站 | 播放通常有 | 三连率、弹幕、完播、UP长期关系 | 播放全时可算效率；社区认可看三连结构 |
| 知乎 | 播放通常无 | 赞同**质量**、专业权威度 | 看赞同+评论，别用播放；排序偏威尔逊类 |
| 快手 | 视情况 | 去中心化、老铁信任关系 | 信任型互动，性价比/下沉语境 |

**通用铁律**：
- 无播放量 → 不要伪造"播放转化率/成功率"，改用**同平台内互动合计的相对位次**。
- 互动合计口径：`likes + comments + collects`（有 shares 再加），别把不同平台的合计直接比大小。

## 4. 效率怎么算（有播放 vs 无播放）

"效率"回答的是：这条内容用多少曝光换来了多少互动（性价比）。

- **有 `play_count`**：`效率 = 互动合计 / play_count`。效率高 = 触达之后的转化力强，是可参考的高质量种草结构。
- **无 `play_count`**（抖音/小红书/知乎常见）：**禁止**造分母。改用同平台本批次内"互动合计"的相对排名，取相对靠前者作为"高效率候选"。

跨平台永远只比**结构和份额**（如"小红书这条在小红书批次里排前 10%"），不比"抖音 5 万 vs 小红书 3 千"。

## 5. 评论数据怎么读

评论是最深的卷入，也是最容易被外行忽略的金矿。三种读法：

### a. 判断内容性质（正面 vs 争议）
- 评论区一片"想要/在哪买/求链接" → **正向种草成功**，是可复用样本。
- 评论区大量"和 XX 比""真的有用吗""踩雷了" → **争议/疑虑**，先别当范例，要提炼具体卡点。

### b. 提炼消费者洞察（痛点句式）
评论里的原话就是消费者的**决策语言**。抓高频的场景、动机、顾虑，用于：
- 洞察卡片（场景+动机+顾虑+建议）
- FAQ / 对比测评 / 避坑清单选题
- 决策语言可作为投放文案与话术素材

### c. 挖线索（Comments Leads）
高意向表达就是潜在客户：
- 「多少钱/哪里买/求链接」= 价格/购买意向
- 「和 XX 比哪个好」= 对比决策中
- 「敏感肌能用吗/转奶怎么弄」= 场景化求助
- 「被种草了想试试」= 已被打动

高评论率的内容优先扫评论——那里意向密度最高。
