## 主题分类（贯穿全篇的基础动作）

几乎所有分析都从"给每条内容归个主题"开始。用固定 6 类，保证可对比、可复用：

`guide`（选购指南）| `negative`（负面舆情）| `price_channel`（价格渠道）| `experience`（体验分享）| `brand_campaign`（品牌战役）| `other`（其他）

**匹配优先级**（一条内容可能沾多个主题时，按此优先）：
`negative` → `guide` → `price_channel` → `experience` → `brand_campaign` → `other`

为什么负面优先？因为舆情风险最需要被看见，宁可先标出来。

## 视角一：理解消费者（Consumer Insights）

回答：**市场在讨论什么？为什么买/不买？**

### 决策议题分布
- 给每条内容打 `topic`，用互动合计加权，算出各议题的声量占比。
- **读法**：占比最高 = 当前决策主战场；`negative`/`price_channel` 偏高 = 信任或渠道焦虑在主导。
- 行业提示：奶粉看转奶/正品，饮料看场景/促销，医药器械看科普/顾虑/合规。

### 洞察卡片（最有价值的产出之一）
从高表现或高活跃的内容 + 其评论里，提炼 3–5 张卡片，每张含四要素：

```
场景（什么情境下）+ 购买动机（想解决什么）+ 主要顾虑（卡在哪）+ 建议方向（内容该怎么做）
```

- 每张卡片必须引用证据内容的 `id`，不能凭空编。
- 这些卡片直接喂给 FAQ、对比测评、避坑清单的选题。

## 视角二：种草（Social Seeding）

回答：**投在哪个平台？参考哪条内容？**

### 平台 × 主题矩阵
- 行 = 主题，列 = 平台，格子 = 条数或互动份额。
- **读法**：
  - 某主题在单平台份额 >40% → 叙事集中在这个平台。
  - 某需求全平台声量都低 → **内容缺口**，是切入机会。
  - 负面主题偏高 → 联动视角三的风险分析。
- 结合平台角色解读（非因果断言）：B站/知乎偏定调，小红书偏信任验证，抖音偏场景收割。

### 可参考种草素材 Top
- 每平台取效率或互动相对 Top（建议每平台 3–5 条）。
- 标形态标签：`scene`场景 | `compare`对比 | `review`测评 | `promo`促销 | `edu`科普 | `ugc`真人体验。
- 小红书优先看**收藏**结构；抖音/B站看播+赞+评结构。
- 目的：告诉用户"这种打法已被验证有效，可以抄结构"。

## 视角三：消费者研究（Consumer Research）

回答：**反馈偏正面还是有争议？有什么风险？**

### 正面 vs 争议结构
用互动结构（见 `reading-metrics.md` 第 2 节）区分：
- **正面型**：赞/藏相对高、评论相对低 → 反馈较一致 → 可参考其结构做种草。
- **争议型**：评/赞比异常高，或藏+评同高 → 讨论多或购买犹豫 → 先整理评论再决定怎么回应。
- 输出两类占比 + 代表内容 id。

### 舆情风险与跟进优先
- 定位 `negative` 主题 + 高评论的内容 → 风险优先级最高。
- 不要只报"有几条负面"，要说清：负面集中在哪个平台、卡在什么环节、建议怎么回应（FAQ / 对比 / 官方澄清）。
- 高评论率的负面内容优先扫评论，找具体卡点和潜在线索。

## 视角四：个性化触达（Personalized Engagement）

回答：**各平台打什么人格？话术按什么意图拆？**

### 平台人格适配
同一产品在不同平台要用不同"人格"说话（详见 `industry-playbook.md`）：
- 抖音打情绪/场景击穿，小红书打对比验证，B站打专业认同，知乎打决策加码，快手打信任性价比。
- 用平台×内容形态的分布，判断每个平台当前缺什么形态的内容。

### 意图脚本清单
- 从标题和评论聚类出用户意图（功效/场景/情绪/成分/价格…）。
- 每个意图对应一套话术方向，供评论区回复、私信、脚本使用。

## 组织输出的建议

**按问题灵活分析时**（大多数情况）：只回答用户问的，用相关视角支撑，结论落到动作。不要硬凑八张表。

**做完整体检时**：可走完整 4 视角，但每个视角结尾都要有"所以要做什么"。建议结构：
```
1. 一句话总览（这个词的市场当前是什么状态）
2. 消费者在讨论什么（议题分布 + 2-3 张洞察卡片）
3. 该投哪、抄什么（平台矩阵 + 可参考内容）
4. 有什么风险（正面/争议结构 + 舆情优先级）
5. 各平台怎么打（人格适配 + 意图话术）
6. 行动清单（3-5 条最该先做的事）
```

**始终记住**：数据是证据，动作是目的。每个结论都要能指回具体内容/评论，也要能指向一个营销决策。
