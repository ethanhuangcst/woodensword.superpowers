# 「这个创作者值不值得合作」评分怎么设计

先说结论：这个功能值得做，但**别做成一个「粉丝越多分越高」的排行榜**——那是最常见、也最贵的外行坑。下面我按「先纠一个认知 → 该看哪些维度 → 怎么算成分数 → 怎么落地实现 → 要避开的雷」的顺序讲清楚，你没有营销背景也能照着搭。

---

## 一、先纠正一个会毁掉整个功能的认知

你现在想要的是一个「值不值得合作」的分。但营销里没有一个放之四海皆准的「好创作者」——**同一个创作者，对不同目的、不同预算、不同行业，值不值得是不同的答案。**

- 你想要的是**声量破圈**（让很多人知道），还是**转化种草**（让人真的去买）？前者看头部大号，后者可能一堆小号更划算。
- 一个 50 万粉的美食博主，对饮料品牌可能很值，对奶粉品牌可能完全不匹配。

所以这个评分不该是一个孤立的绝对分，而应该是**「针对某个合作目的、某个行业」的相对适配分**。实现上，建议你让用户在评分前先选两件事：**合作目的**（声量 / 转化 / 口碑背书）和**行业**（你们覆盖快消饮料、奶粉、制药、医疗、器械）。同一个创作者，换个目的，分数和维度权重就该跟着变。这一点后面会具体落到权重上。

第二个必须先立的规矩：**不要跨平台直接比绝对数。** 抖音一条 10 万播放和小红书一条 1 万赞，不能说抖音这个号更强——各平台量级、字段口径、用户行为完全不同。评分里所有「表现好不好」的判断，都要在**同平台、同粉丝量级**内部比相对位次，绝不能拿抖音的播放去和小红书的收藏加总或比大小。这是评分算法最容易埋的暗雷。

---

## 二、该看哪些维度（每个维度先讲「为什么」）

粉丝数只是入场券，不是答案。真正决定「值不值」的是下面 6 个维度。我按重要性从高到低排。

### 维度 1：垂类匹配度（Relevance）——这是「门槛」，不是「加分项」

**为什么最重要**：一个和你产品不搭的号，粉丝再多、互动再好，都不值得合作，因为他的观众不是你的潜在买家。匹配度差的号应该**直接被扣到很低甚至一票否决**，而不是靠其他维度分高把它拉回来。

看什么：
- 创作者常发的**内容主题**和你的产品品类是否重合（可以复用技能里的主题分类：选购指南 / 体验分享 / 价格渠道 / 品牌战役 / 负面 等）。
- **行业钩子命中度**：奶粉看他是否聊转奶、正品版本、安全；饮料看他是否聊场景、口味、促销；医疗器械看他是否做使用教程、正品辨别。命中你行业的核心焦虑，匹配度才算高。
- 受众画像是否对得上你的目标人群。

### 维度 2：互动质量（不是互动总量）——判断影响力是真是假

**为什么关键**：粉丝数和播放量都能买，但**互动结构骗不了人**。外行看「多少赞」，专家看「赞、藏、评之间的比例」。

看什么（核心手艺，务必内化）：
- **互动率**（互动合计 ÷ 触达），而不是绝对互动数。一个 5 万粉但每条几千真实互动的号，往往比 50 万粉互动稀薄的号更值。
- **重动作占比**：收藏和评论是「重动作」，比点赞值钱得多。
  - **收藏高** = 观众想「留着照做 / 照买」，是极强的决策/购买意图信号（小红书尤其要单独看收藏）。
  - **评论盖过点赞** = 引发了真实讨论。这是双刃剑，要去读评论区判断是「求链接」（好）还是「踩雷 / 真有用吗」（风险，见维度 5）。
  - **只有赞、藏和评都很少** = 叫好不叫座，甚至是刷量号。
- **真实性信号**：互动率异常高但评论内容空洞重复、粉丝暴涨曲线不自然 = 疑似水军，应扣分而非加分。

一句话：这个维度的目标是回答「他的影响力是真的能带动观众行动，还是只是数字好看」。

### 维度 3：种草转化力——他的观众会不会真的下单

**为什么单列**：影响力大不等于卖得动货。有的号观众只是来看热闹（赞多藏少），有的号观众是带着购买决策来的（藏高、评论里全是「多少钱 / 哪里买 / 和 XX 比」）。

看什么：
- 评论区的**购买意向密度**：「求链接 / 在哪买 / 敏感肌能用吗 / 转奶怎么弄」这类高意向表达越多，转化力越强。
- 内容形态是否偏**测评 / 对比 / 避坑 / 使用教程**（决策验证型），而不是纯情绪或纯搞笑。
- 是否处在决策链路的**承接位置**（小红书搜索种草、知乎决策加码这类平台的匹配内容）。

如果你的合作目的是「转化」，这个维度权重要最高；如果是「声量破圈」，这个维度可以降权。

### 维度 4：内容稳定性与产能——合作能不能持续、可预期

**为什么要看**：一次爆款可能是运气，能持续稳定产出中上水平的号，合作风险才低。

看什么：
- **更新频率**是否稳定（长期停更、断更的号要谨慎）。
- 历史内容表现的**波动性**：是稳定中上，还是一条爆、九条扑（后者不可预期）。
- 是否**系列化、有主线**（尤其 B站，长期关系型平台，稳定产出的 UP 更有沉淀价值）。

### 维度 5：舆情与合规风险——这是「减分项 / 一票否决项」

**为什么必须独立成维度**：一个翻过车、有黑历史、或惯于打擦边违规内容的号，一旦合作可能把品牌一起拖下水。风险维度不该和优点相加抵消，而应作为**惩罚项或否决项**。

看什么：
- 历史内容里的**负面舆情**（被大量质疑、踩雷投诉、和粉丝对骂）。
- **刷量 / 水军**痕迹（见维度 2）。
- **合规红线（制药 / 医疗 / 器械行业必查）**：创作者是否有夸大疗效、暗示确定治愈、编造有效率/成功率等违规表述。有这类历史的号，在这些强监管行业里应**直接一票否决**，不能因为其他分高就推荐——这不仅是效果问题，是法律风险。
- 商业内容是否过密（一水儿硬广），这类号观众信任被透支，种草效果打折。

### 维度 6：平台适配与商业化历史——他在哪个战场、带过货没有

看什么：
- 创作者的**主阵地平台**是否是你这次要打的平台，以及该平台的角色是否匹配你的目的（抖音情绪场景收割、小红书决策验证、知乎专业加码、B站圈层定调、快手信任性价比）。
- 是否有**过往商业合作**且数据可读（接过广告后互动是否崩、评论口碑如何）。有干净的带货历史是强加分。

## 三、怎么把维度变成一个分数（可直接实现的设计）

不建议做成「六项打分简单相加」。原因是匹配度和风险这两项性质特殊：匹配度差应该一票压低，风险高应该直接惩罚。推荐下面这种**「门槛 + 加权 + 惩罚」的混合结构**：

```
最终得分 = 基础分(0–100) × 匹配度系数 × 风险系数
```

其中：

**1）基础分 = 维度 2/3/4/6 的加权和**（这几项是「他好不好」的正向能力）。权重随**合作目的**动态调整：

| 维度 | 声量破圈目的 | 转化种草目的 | 口碑背书目的 |
|------|:---:|:---:|:---:|
| 互动质量 | 高 | 中 | 中 |
| 种草转化力 | 低 | 最高 | 中 |
| 内容稳定性 | 中 | 中 | 高 |
| 平台适配 | 高 | 中 | 中 |

（具体数字你可以先用一组默认权重，比如各 25%，上线后按回收的实际合作效果再调。）

**2）匹配度系数（0–1）**：垂类完全对口给 1，完全不搭给 0.2 以下。它是乘数，所以不匹配的号无论其他分多高，最终都上不去。这就实现了「匹配度是门槛不是加分」。

**3）风险系数（0–1，且带硬否决）**：无风险给 1，有轻微风险打折（如 0.7），触及**合规红线或严重翻车**直接给 0 / 标记为「不推荐合作」，并附一句人话原因（比如「该号存在夸大疗效表述，制药行业合规风险，不建议合作」）。

**4）每个维度内部怎么打分——关键：同平台、同量级归一化。**
- 不要用绝对值。把候选创作者放进「同平台 + 同粉丝量级（KOL / 腰部 / KOC 素人分档）」的池子里，算**相对位次或百分位**，再映射到 0–100。
- 缺字段就诚实处理，不要伪造：抖音、小红书常拿不到播放量，这时**禁止硬算「播放转化率」**，改用同平台互动合计的相对排名。缺数据的维度应标「数据不足」并降低它在总分里的权重，而不是默认给高分或低分。

**5）不要只吐一个数字，要给「分数 + 理由 + 建议」。** 用户没有营销背景，一个 73 分对他没意义。每个评分应该配：
- 一句话总评（「适合做转化型种草的腰部 KOC，慎用于品牌声量」）。
- 3 条最关键的加分 / 减分理由，每条都能指回证据（哪条内容、哪些评论）。
- 一个明确动作建议（值得合作 / 观察备选 / 不建议，以及适合什么形态的合作）。

这也符合「每个数字都要翻译成营销含义和动作」的原则——评分的终点是决策，不是报表。

## 四、一个可以照抄的落地路径（建议按用户故事逐个交付）

别想一次做全。建议拆成能独立上线的小步：

1. **v0 最小版**：先只做「匹配度 + 互动质量 + 风险」三个维度，输出「分数 + 一句话理由 + 建议」。这三项已经能拦掉大部分不值得合作的号，价值最高。
2. **v1**：加入「种草转化力」和「合作目的可选」，让权重随目的变化。
3. **v2**：加入「稳定性 / 产能」和「商业化历史」，并补上同平台同量级的归一化和百分位。
4. **持续校准**：把实际合作后的真实效果回收回来，反过来校准权重——这是让评分越用越准的唯一正路。

界面上记得：这是给「没有营销背景的用户」看的，评分维度名、理由、建议**都要用大白话**，别堆专业术语；文案按 i18n 处理，不要写死。

---

## 五、必须避开的 5 个雷（都是外行常犯的）

1. **不要跨平台比绝对数**，更不要把抖音播放和小红书收藏加总。一切比较在同平台、同量级内做。
2. **不要迷信粉丝数和播放量**——都能刷。看互动结构（赞/藏/评比例）和评论真实度。
3. **不要让优点抵消风险**。合规红线和严重翻车必须是乘数/否决，不能被高分掩盖。制药、医疗、器械行业尤其要硬卡合规。
4. **缺数据就说缺，不要伪造指标**。没有播放量就别算转化率，用相对位次代替。
5. **不要只给一个分数**。分数 + 可回溯的理由 + 一个动作建议，才是这个功能真正的价值所在。
