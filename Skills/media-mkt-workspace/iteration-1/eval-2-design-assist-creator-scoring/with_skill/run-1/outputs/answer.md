# 「这个创作者值不值得合作」评分怎么设计

先说一个容易踩的坑：**「值不值得合作」不是一个绝对分数，而是「对你这次投放的目标，值不值」。** 同一个创作者，你要「品牌背书破圈」还是「便宜铺量、堆真实口碑」，答案完全相反。所以在动手设计分数前，先想清楚一件事——这套评分是用来干嘛的。下面我先帮你把这件事讲透，再给维度、给算分方法、给产品该长什么样。

---

## 一、先纠正一个外行直觉：别把粉丝数当主分

没有营销背景的人第一反应通常是「粉丝越多越值得合作」。这是最贵的错误。原因：

- **粉丝数只代表触达规模，不代表转化。** 100 万粉但没人互动的账号，可能是买来的僵尸粉；5 万粉但评论区全是「求链接」的账号，带货可能更猛。
- **行业里其实分两种合作对象**，目标不同、评分逻辑也不同：

| | KOL（大 V / 关键意见领袖） | KOC（素人 / 关键意见消费者） |
|---|---|---|
| 你为什么找他 | 声量、权威、破圈背书 | 真实感、便宜、铺量形成「很多人都在用」 |
| 看重什么 | 影响力 + 不翻车 | 转化率 + 垂类真实度 |
| 风险 | 贵、广告感重、翻车影响大 | 单点声量小、质量参差 |

你的评分系统最好**先让用户选「合作目的」（造声量 / 促转化 / 铺口碑）**，不同目的下各维度的权重不一样。这一步做了，后面的分才有意义。

## 二、该看哪些维度（6 个，分两类）

我把维度分成 **「加分项」（决定值不值）** 和 **「一票否决项」（决定能不能碰）**。这是关键设计——有些东西不是扣分就能补的，比如医疗行业内容违规，再高的数据也不能合作。

### A. 加分维度（算综合得分）

**① 垂类匹配度（最重要，建议权重最高）**
这个创作者平时讲的东西，和你的产品/行业是不是一路人？
- 一个天天讲奶粉转奶、正品鉴别的母婴博主，对你卖奶粉的价值，远大于一个粉丝更多的泛生活博主。
- **怎么量化**：看他历史内容的主题分布，落在你的行业钩子上的占比越高越好。比如奶粉看「转奶焦虑 / 正品版本 / 安全」，饮料看「场景 / 促销 / 口味」，医疗器械看「使用方法 / 真伪辨别」。匹配主题占比 → 直接换算成分数。

**② 真实互动质量（不是互动总量，是结构）**
这是把你和外行拉开差距的核心。**同样 1000 赞，结构不同，价值天差地别：**
- **看「重动作」占比**：收藏和评论是「重动作」，比点赞值钱得多。
  - **收藏高** = 用户「想留着照做/照买」，是极强的购买意图信号（尤其小红书）。
  - **评论 ≥ 点赞** = 内容能引发讨论，评论区是线索金矿（前提是正向讨论，不是骂声）。
  - 只有点赞高、收藏评论都低 = 「叫好不叫座」，看着热闹但不带货。
- **怎么量化**：算这个创作者内容的**互动率**（互动合计 ÷ 粉丝或曝光）和**收藏/评论占比**，两个都高才是好账号。互动率还能反向识别僵尸粉——粉丝几十万但互动率极低，基本是刷的。

> ⚠️ 一个技术提醒给你的工程实现：**不同平台的数字不能直接比大小。** 抖音常拿不到播放量、小红书收藏权重极高、B站看三连、知乎看赞同质量。所以「真实互动质量」这一维度，**要在同平台内部横向排名后再折算成分数**（比如「他在同类账号里排前 10%」），不要用「抖音 5 万 vs 小红书 3 千」这种跨平台绝对值去比。

**③ 内容稳定性 / 更新健康度**
偶尔爆一条 vs 持续稳定产出，合作价值不同。看：更新频率是否稳定、近期数据是不是断崖下跌（掉粉/限流征兆）、有没有长期做同一垂类（专业度积累）。B站、知乎这类账号尤其看「长期关系」。

**④ 平台适配度**
这个创作者的主阵地，是不是你这次要打的平台？各平台人格不同：
- 抖音打情绪/场景击穿、小红书打对比验证种草、B站打专业深度、知乎打决策加码、快手打信任性价比。
- 一个擅长小红书测评的账号，硬拉去抖音做情绪短视频未必行。**评分时把「他的主场 = 你的目标平台」作为加分。**

### B. 一票否决维度（红线，触发即降级或拉黑）

**⑤ 舆情 / 翻车风险**
- 历史有没有翻车、被打假、评论区大量负面（「踩雷了」「真的有用吗」「和 XX 比差远了」）。
- 有没有明显的**水军痕迹**：评论清一色模板夸赞、互动率和内容质量严重不匹配。
- **设计建议**：这一项不做加分，做**扣分/否决**。风险高的账号，数据再好也要显著降级，甚至标红「谨慎合作」。

**⑥ 合规风险（你的行业是重灾区，必须单独做）**
你覆盖制药、医疗、医疗器械——这是强监管行业。如果一个创作者惯用**夸大疗效、暗示确定治愈、编造有效率/成功率**这类表述，**不管数据多好，都应直接判定「不可合作」**，而不是扣几分了事。和这种账号合作，风险是你的品牌承担的。这一项建议做成硬性一票否决。

## 三、怎么把维度变成一个分数（具体算法建议）

给你一个能直接落地、又不会误导人的结构：

```
最终结果 = 合规/风险闸门  ×  加权综合分

第一步（闸门，先过滤）：
  - 合规红线命中          → 直接判「不可合作」，不进入打分
  - 舆情/水军高风险       → 打「⚠ 谨慎」标签，综合分封顶（如最高只给 60）

第二步（加权综合分，0–100）：
  综合分 = 垂类匹配 ×w1 + 互动质量 ×w2 + 内容稳定 ×w3 + 平台适配 ×w4
  权重随「合作目的」切换，例如：
    · 促转化：  互动质量 40% + 垂类匹配 30% + 平台适配 20% + 稳定 10%
    · 造声量：  垂类匹配 30% + 平台适配 30% + 互动质量 25% + 稳定 15%
    · 铺口碑：  垂类匹配 35% + 互动质量 35% + 稳定 20% + 平台适配 10%
```

**几个设计原则，帮你避免把分数做成一个「看起来精确、其实误导人」的黑箱：**

1. **每个维度的原始数据要在同平台内做归一化**（排名百分位），再进加权，避免跨平台不可比的问题。
2. **不要输出一个孤零零的数字。** 「78 分」没人敢据此签合同。要给**分档 + 理由**：
   - 🟢 推荐合作（垂类高度匹配、互动真实、无风险）
   - 🟡 可考虑（某维度突出但有短板，说明短板是什么）
   - 🔴 不建议 / 谨慎（触发风险或合规红线）
3. **分数旁边永远附「为什么」**：比如「垂类匹配 92 分——近 30 条内容 21 条聊转奶/正品，正中你的产品；但互动质量仅 55 分——收藏率低于同类账号，偏‘叫好不叫座’，适合造声量不适合直接带货。」这样用户才知道拿这个分去干嘛。
4. **缺数据就标缺，别硬编。** 抖音/小红书常拿不到播放量，就别硬算「转化率」，用互动合计的相对排名代替，并在界面注明口径。伪造指标比缺指标更危险。

## 四、产品界面上建议怎么呈现

一个「创作者评分卡」，从上到下：

1. **一句话结论 + 分档标签**：`🟢 推荐合作 · 82分 · 适合小红书促转化`
2. **雷达图 / 六维条**：让用户一眼看到强在哪、弱在哪。
3. **风险栏（单独醒目）**：合规、舆情、水军三项，有就飘红，没有就打绿勾。
4. **证据区**：点开每个维度能看到支撑的具体内容和评论（「这条 3.8 万赞、评论区大量求链接」），不能只给分不给依据。
5. **给一句可执行建议**：不只是评分，还告诉用户「建议以 KOC 形式合作、主打转奶避坑主题、内容放小红书」——这才是你的智能体比一张表值钱的地方。

---

## 五、三条一定要记住的红线（帮你少走弯路）

1. **别让粉丝数或互动总量主导分数**，垂类匹配 + 互动结构（收藏/评论）才是核心。
2. **跨平台只比份额和排名，不比绝对值**，否则整套分数从底层就是错的。
3. **合规和舆情做「一票否决」，不做扣分**——尤其你做医疗/制药，一次违规合作的代价远超一个高分账号带来的收益。

---

### 建议的落地顺序（先做能用的最小版本）

如果你想先跑起来，建议按这个顺序做，别一次全上：

1. **先做闸门**：合规红线 + 舆情/水军风险识别（哪怕先用关键词 + 人工复核）。这是保命的。
2. **再做两个核心加分维度**：垂类匹配度、真实互动质量（含同平台归一化）。这两个就能覆盖大部分判断。
3. **最后补** 内容稳定性、平台适配、以及「合作目的切换权重」的高级功能。

先把「不会推荐一个违规/翻车账号」和「不会被僵尸粉骗到」这两件事做扎实，你这个评分就已经比市面上多数只看粉丝数的工具靠谱了。
